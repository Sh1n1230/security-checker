# 0002. ドキュメントの正典言語は当面日本語

- 状態: 採用 (2026-09-15。NEXT-STEPS の D10)
- 関連: DESIGN.md §30.1

## 背景

設計書は英語を正典としている (OSS として広く使ってもらうため)。一方、作者は日本語話者で、
開発中は設計と実装が頻繁に変わる。2 言語を並行して保つと、更新漏れで食い違う。

## 決定

- 開発中 (v2.0.0 まで) のドキュメントは日本語を正典とする。
- 英語化は P6 (公開) でまとめて行う。README から始め、英語を正典に切り替える。

## 結果

- 英語圏の利用者には、v2.0.0 まで README 以外が読みにくい。
- 切り替え後は英語を先に更新し、`README.ja.md` を追従させる。
