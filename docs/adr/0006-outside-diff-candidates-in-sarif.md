# 0006. diff の範囲外の候補も SARIF に note で残す

- 状態: 採用 (2026-10-04)
- 関連: DESIGN.md §7.4, §18.4.2

## 背景

PR では変更行に関係する候補だけをレビューする (diff モード、コストのため)。
では変更に関係しない候補を SARIF にどう出すか。

- **出さない**: SARIF は「このツールがこの run で見つけた全て」と解釈されるため、既定ブランチにある
  alert が PR の解析では「修正済み」に見える。
- **スキャナの重大度で出す**: 既定ブランチで LLM が誤検知と判定して出していない候補が、PR では
  新しい error として現れ、無関係な PR がゲートで止まる。

## 決定

- diff の範囲外の候補は `level: note`・`security-severity: 0.0`・`properties.status: outside_diff` で出す。

## 結果

- 既存 alert は閉じず、PR のゲートにも掛からない。
- PR の解析結果には、変更と無関係な note が並ぶことがある (ノイズ)。Code Scanning の
  「この PR で新しく出たもの」の表示で区別できる。
